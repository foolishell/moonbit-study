## ルーティング

### MoonBit

`moonbitlang/async` の HTTP ライブラリは axum のような宣言的ルーターを持たない。
パターンマッチで手書きする。

```moonbit
server.run_forever() <| ((request, _body, conn) => {
  match (request.meth, request.path) {
    (Get, "/")       => send_json(conn, 200, "{...}")
    (Get, "/health") => send_json(conn, 200, "{...}")
    _                => send_json(conn, 404, "{...}")
  }
})
```

シンプルだが、パスパラメータ（`/users/:id`）の抽出は自前実装が必要。

### axum

```rust
let app = Router::new()
    .route("/",        get(root_handler))
    .route("/health",  get(health_handler))
    .route("/users/:id", get(user_handler));

axum::serve(listener, app).await?;
```

`Router` が型レベルでルーティングを保証し、パスパラメータも `Path<(u32,)>` で自動抽出。

## リクエスト / レスポンス

### MoonBit

レスポンスは低レベル API を組み合わせて送る。

```moonbit
async fn send_json(conn : @http.ServerConnection, code : Int, body : String) -> Unit {
  let headers : @http.Headers = Map([
    (@http.CaseInsensitiveString("Content-Type"),   "application/json"),
    (@http.CaseInsensitiveString("Content-Length"), body.length().to_string()),
  ])
  conn.send_response(code, "OK", extra_headers=headers)
  conn.write_string(body)
  conn.end_response()
}
```

ヘッダーのキーが `CaseInsensitiveString` 型であるなど、まだ API が荒削り。

### axum

```rust
async fn root_handler() -> impl IntoResponse {
    Json(json!({"message": "Hello from axum!"}))
}
```

`Json<T>` / `StatusCode` などの型が `IntoResponse` を実装しており、返すだけでよい。

## まとめ

| | MoonBit | axum |
|---|---|---|
| 学習コスト | 低（API がシンプル） | 中（Tower / 型システム） |
| 生産性 | △（ボイラープレートが多い） | ◎ |
| 型安全性 | ○（言語レベル） | ◎（ルーターも型安全） |
| 本番利用 | ❌ 未成熟 | ✅ 実績あり |
| マルチターゲット | ✅ native/wasm/js | ❌ native のみ |
| 将来性 | 🔭 注目株 | ✅ 安定 |

MoonBit の HTTP ライブラリは現時点では低レベルで、実用的な Web サービスを作るには
`bobzhang/crescent` 等のサードパーティフレームワークが必要になるケースが多い。
一方で言語自体の表現力（パターンマッチ・型推論・マルチターゲット）は高く、エコシステムの成熟に期待。
