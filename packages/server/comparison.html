ルーティング

MoonBit
server.run_forever() <| ((req, _, conn) => {
  match (req.meth, req.path) {
    (Get, "/")       => handle_root(conn)
    (Get, "/health") => handle_health(conn)
    _                => send_404(conn)
  }
})
  • シンプルで追加依存なし
  • パターンマッチで網羅性チェック
  • パスパラメータ非サポート（自前実装）
  • ミドルウェアなし
axum
let app = Router::new()
    .route("/", get(root))
    .route("/health", get(health))
    .route("/users/:id", get(user))
    .layer(TraceLayer::new_for_http());

axum::serve(listener, app).await?;
  • 宣言的ルーター
  • パスパラメータを型安全に抽出
  • Tower ミドルウェアを合成可能
  • 学習コストがやや高い

リクエスト / レスポンス

MoonBit — 手動でヘッダーとボディを送信
async fn send_json(
  conn : @http.ServerConnection,
  code : Int,
  body : String,
) -> Unit {
  let headers : @http.Headers = Map([
    (@http.CaseInsensitiveString("Content-Type"),
     "application/json"),
    (@http.CaseInsensitiveString("Content-Length"),
     body.length().to_string()),
  ])
  conn.send_response(code, "OK", extra_headers=headers)
  conn.write_string(body)
  conn.end_response()
}
axum — 型が IntoResponse を実装
async fn root() -> impl IntoResponse {
    Json(json!({"message": "Hello!"}))
}

// エラーも返せる
async fn user(
    Path(id): Path,
) -> Result<Json<User>, StatusCode> {
    db::find(id)
        .await
        .ok_or(StatusCode::NOT_FOUND)
        .map(Json)
}

エラーハンドリング

MoonBit

HTTP レベルのエラーレスポンス変換は手動。catch で拾ってステータスコードにマップする。

server.run_forever() <| ((req, _, conn) => {
  handle(req, conn) catch {
    NotFound(msg) => send_json(conn, 404, ...)
    BadRequest    => send_json(conn, 400, ...)
    _             => send_json(conn, 500, ...)
  }
})
axum

IntoResponse を実装した独自エラー型を返すだけ。thiserror と組み合わせて体系的に管理できる。

#[derive(thiserror::Error, Debug)]
enum AppError {
    #[error("not found")]
    NotFound,
}
impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        (StatusCode::NOT_FOUND, self.to_string())
            .into_response()
    }
}

MoonBit の HTTP ライブラリは現時点では低レベルで、実用的な Web サービスには bobzhang/crescent 等のサードパーティフレームワークを使うか、 ルーター層を自前で作る必要がある。 言語自体の表現力（パターンマッチ・型推論・マルチターゲット）は高く、エコシステムの成熟に期待。
